# Security

This skill reads a person's inbox while scammers are actively targeting them, so bypasses matter.

## Please report

- An email or web page that makes an agent using this skill take an action: send, forward, label, click, enroll or contact anyone.
- A way to get sensitive details (SSNs, member IDs, codes, test names or results) or remote images into a report or the state file.
- A scam that `check_sender.py` misses in a way the skill's instructions don't catch.

Use GitHub's **Report a vulnerability** button on the Security tab. Please don't open a public issue for a working bypass. Describe the pattern and include a fictional sample message; never send real personal data.

## Out of scope

Weaknesses in the underlying AI model or mail connector that don't involve this skill. Report those to the vendor.
